# BEI 加重平均シミュレーター

建築物のエネルギー消費性能（BEI）の加重平均を対話的に計算するWebアプリです。

## 概要

BEI/ALL は以下5用途の BEI を加重平均して算出されます。

| 記号 | 用途 |
|------|------|
| AC | 空調 |
| V | 換気 |
| L | 照明 |
| HW | 給湯 |
| EV | 昇降機 |

$$
\text{BEI/ALL} = \frac{\sum (w_i \times \text{BEI}_i)}{\sum w_i} \quad (\sum w_i = 100)
$$

## 機能

- **スライダー連動**: 1つの重みを変更すると、他の項目が自動調整され合計100%を維持
- **ロック機能**: 鍵アイコンで特定用途の重みを固定（最大4つまで）
- **リアルタイム計算**: BEI値と重みの変更が即座に結果に反映
- **ZEB基準表示**: BEI ≤ 1.0 で緑、超過で赤表示
- **ダークモード対応**
